# 🚆 RailEase — Railway Ticket Booking Web App

**RailEase** is a modern and responsive railway ticket booking web application built with React, JavaScript, and CSS. It provides a complete end-to-end booking experience from train search to e-ticket generation.

---

## ✨ Features

- **Train Search & Filters**: Search trains across 25+ stations, filter by departure time, train class (`1A`, `2A`, `3A`, `SL`, `CC`, `EC`), and train category (*Vande Bharat, Rajdhani, Shatabdi, Superfast*).
- **Multi-Passenger Booking**: Add up to 6 passengers with berth preferences (*Lower, Middle, Upper, Window*) and meal choices.
- **Payment Simulation**: Interactive checkout with UPI QR code scan, Credit/Debit cards, and NetBanking.
- **Digital e-Ticket**: Realistic reservation slip with allocated Coach/Berth, QR code, and **Print to PDF** support.
- **My Bookings**: View saved tickets and cancel bookings with refund calculation (persisted in `localStorage`).
- **PNR Status Tracker**: Check real-time 10-digit PNR reservation status.
- **User Authentication**: Sign In / Sign Up modal with a one-click Demo Login.
- **Responsive Design**: Works on mobile, tablet, and desktop screens.

## 🚀 How to Run

### Option 1: Run Directly in Browser (No setup needed)
Simply **double-click `index.html`** in this folder to open and run the app directly in your browser.

---

### Option 2: Run with Vite Development Server
If you want to run the project using Node.js / Vite:

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the dev server:
   ```bash
   npm run dev
   ```

3. Open **`http://localhost:5173`** in your browser.
