# RailEase

RailEase is a frontend railway ticket booking web application built with React.js, JavaScript, HTML/JSX and CSS.

## Run in VS Code

1. Install Node.js.
2. Open this folder in VS Code.
3. Open the terminal.
4. Run:
   npm install
   npm run dev
5. Open the localhost address shown by Vite.

## Current features

- Responsive homepage
- Railway search form
- Station swap
- Train filtering by class
- Train result cards
- Passenger details
- Booking review
- Ticket confirmation
- Print ticket
- Mock train data

MongoDB/backend can be connected later.
